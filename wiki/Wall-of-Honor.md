## 🤖 How Automation Works

This Wall of Honor is **100% automatically synchronized**:
1. When a supporter sponsors the project via **GitHub Sponsors**, GitHub sends a `sponsorship` event.
2. A automated **GitHub Action (`update-sponsors.yml`)** queries the GitHub GraphQL API, categorizes supporters into their respective tier, and updates this document.
3. The changes are automatically synced directly to the live GitHub Wiki within seconds. No manual intervention required!
